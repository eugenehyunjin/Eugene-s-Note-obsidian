문제점:
- 실제 입차 일시 등록 시, 관리자가 임의로 마음대로 등록 가능, 그로인해 차량 관제 회사(아마노)에서 실제 입차 기록이 있는 경우, 출차 정보가 수신이 되어도 출차 처리 불가능
개선점:
1. 입차 여부 확인 체크박스 클릭 시, 아마노 차량 관제 회사인지 체크 후, 아마노의 경우 api로 아마노 관제 서버에 해당 차량 번호가 입력한 방문일시, 출차 일시 사이에 입차 기록이 있는지 조회 진행
2. 조회했을 때 입차 정보가 있는 경우, 실제 입차 정보를 입력(수정불가), 아마노의 경우 출차시 실제 입차 시간을 대조하여 출차 정보 입력하기 때문에 출차 입력이 정상 처리되도록 처리하는 과정
3. 조회 했을 때, 입차, 출차 정보 모두 있는 경우, 해당 차량은 아마노 관제 서버에서 입력한 방문 일시와 출차 일시 사이에 이미 입/출차 기록이 모두 있기 때문에, 입차 기록 불필요 "입력하신 방문일시와 출차일시 사이에 이미 출차된 상태입니다.\n해당 차량은 입차 등록이 불필요합니다." 안내 문구 표시
4. 실제 입차 기록이 없는 경우 "입력하신 방문일시와 출차일시 사이에 입차 기록이 없습니다.\n임의로 입차 일시를 입력하실 경우, 관제사로부터 자동 출차 처리되지 않을 수 있습니다." 안내 문구 표시 입차 일시 입력 입력 허용
5. 아마노 사용 단지가 아닌 경우, "임의로 입차 일시를 입력하실 경우, 관제사로부터 자동 출차 처리되지 않을 수 있습니다." 라는 안내 문구 표시 후, 입차 일시 입력 입력 허용(이노메트릭스의 경우 실제 입차 기록을 기반으로 출차 기록하지 않으므로 출차 처리 가능)
