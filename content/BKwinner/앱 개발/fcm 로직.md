서버에 FCM 토큰 저장하기 -> DB에 발급 받은 fcm 토큰을 저장하는 작업

전체 로직:
회원가입 시 firebase에 fcm 토큰을 발급 받음 -> 발급 받은 토큰을 유저 정보와 같이 DB 서버에 저장 -> 이제 앱 서버에서 api를 통해 firebase에게 알림을 특정 유저에게 보낼 수 있는 기능 개발 -> 해당 기능을 통해 firebase에 알림 발송 요청 -> 기존 발급한 fcm 토큰을 이용해서 개인 유저를 구별하여 알림 발송 요청 가능

확인이 필요한 사항:
알림 받는 내용이 무엇이 있는지 확인 필요
- 공지사항, 

현재 웹 관리자 페이지에서 공지사항 등록 시, 웹에서 해당 유저의 fcm 토큰을 가져와서 파이어 베이스에 요청 하는 방식일 것으로 보여짐

- 웹에서 회원가입할 때, 파이어 베이스 정보가 입력이 되는지 확인이 필요
- 현재 user 테이블에만 fcm 토큰을 저장하고 있음
