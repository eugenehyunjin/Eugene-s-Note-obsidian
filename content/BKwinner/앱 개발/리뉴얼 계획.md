아파트리 앱 리뉴얼 작업 계획 
### **1. 작업 분류 및 예상 시간**

**1) 기획 및 요구사항 정의 (1~2주)**

- 페이지별 기능 정의 및 워크플로 작성. (진행중)
- 기존 앱 분석: 유지할 기능, 개선할 부분 정리. (진행중)
- UI/UX 개선 사항 디자이너와 협의. (진행중)

**2) 디자인 작업 (3~4주)**

- 새로운 UI/UX 제작(Figma).
- 주요 페이지 프로토타입 제작.
- 아파트리 직원들의 피드백 및 수정 반영.

**3) 플러터 개발 (6~10주)**

- **플러터 프로젝트 초기 세팅 (1주):**
    - 프로젝트 구조 설정, 플러터 패키지 선정, Git 세팅 등.
    - 템플릿 사용 결정 시 템플릿 초이스.
- **기능 개발 (4~6주):**
    - 주요 페이지별 위젯 구현.
    - API 연동 및 데이터 처리.
- **특수 기능 구현 (1~2주):**
    - 푸시 알림, 폼 처리, 파일 업로드, 지도 연동 등.

**4) 백엔드 및 웹 연동 (1~2주)**

- 웹 개발자의 API 서포트.
- 데이터 모델, 인증 로직 연동 확인.

**5) QA 및 디버깅 (2~4주)**

- 단위 테스트 및 통합 테스트 수행.
- 성능 최적화 및 오류 수정.
- QA는 전직원 참여 요청 필수.

**6) 배포 준비 및 릴리즈 (1주)**

- 앱스토어, 구글 플레이 스토어 릴리즈 준비.
- 테스트플라이트 또는 내부 테스트 진행.

---

### **2. 총 예상 기간**

- 최소: **16주(4개월)**
- 최대: **24주(6개월)**
- 변수로 인한 시간 변동 가능: 외부 API 연동 오류, 기존 유지보수 업무 추가, 센터 업무 요청 등
