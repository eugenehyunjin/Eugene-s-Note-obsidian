로컬 환경 세팅
- AutoSet 프로그램을 통해 기본 php 로컬 서버 환경 세팅 바로 완료 가능
- 로컬에서 개발 하기 위한 xampp를 사용해서 로컬 개발 환경 세팅하기

문제점: xampp 로컬 환경에서 세팅 할 때, php.ini의 extension으로 인한 오류 발생 
1. Undefined class constant 'MYSQL_ATTR_COMPRESS' &  Class 'mysqli' not found
위의 문제는 php.ini에 아래의 extension활성화 텍스트를 입력해주고 아파치 재시작을 통해 해결 완료
extension=C:\xampp\php\ext\php_mysqli.dll
extension=C:\xampp\php\ext\php_pdo_mysql.dll

2. 로컬에서 개발 환경 세팅 시, AC_URL 설정에 대한 값이 localhost로 세팅이 되어야 기본 이용이 가능하게 되므로, 반드시 localhost:80포트로 세팅을 해줘야 js, css파일 코드가 적용이 됩니다.
