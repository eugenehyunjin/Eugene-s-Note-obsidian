
메인 슬로건:
- 편리한 아파트 생활의 새로운 기준
- 쉽고 빠른 아파트 관리의 시작
- 우리 아파트의 모든 것을 한눈에

기능별 마케팅 문구: 
1. 관리비 고지서
	- **"복잡한 관리비? 터치 한 번으로 확인하세요!"**
	- **"종이 청구서 대신 스마트하게 관리비를 확인하세요."**

2. 공지사항 확인
	- **"우리 아파트의 소식을 가장 빠르게!"**
	- **"중요 공지를 놓치지 않도록 알림까지 확실히!"**

3. 설문 및 투표
	- **"내 의견이 반영되는 아파트, 참여로 함께 만들어가요."**
	- **"간단한 투표로 이웃과 함께 결정하세요!"**

4. 주차/예약 관리
	- **"주차장 예약, 이제는 손쉽게!"**
	- **"필요한 공간, 필요한 시간에 간편 예약하세요."**

5. 입주민 커뮤니티
	- **"이웃과 더 가까워지는 소통의 장, 아파트리"**
	- **"아파트 안에서 필요한 모든 정보를 이웃과 공유하세요."**

6. 앱 다운로드 유도
	- **"지금 앱을 다운받아 더 편리한 아파트 생활을 누리세요."**
	- **"PC에서 시작하고, 스마트폰으로 이어가세요."**


**메인 페이지 구조 설계**:
    - **Hero 영역**:
        - 눈에 띄는 슬로건 + 다운로드 버튼 + 간단한 서비스 소개.
    - **핵심 기능 설명**:
        - "관리비 확인", "공지사항", "설문 투표" 등 핵심 기능 섹션 구성.
        - 각 섹션에 관련 이미지를 함께 제공.
    - **고객 후기 및 신뢰 증대 요소**:
        - 실제 사용자 후기, 이용 사례, 협력 아파트 리스트.
    - **CTA(Call to Action)**:
        - "지금 앱을 다운로드하세요" 버튼을 페이지 곳곳에 배치.


css: Tailwind CSS

웹 메인 리뉴얼 작업 기획
1. 수정할 페이지
	- 메인페이지
	- 공지사항 페이지(게시판)
	- 제휴 문의
	- 광고 문의
2. 새로운 구조 모듈화
	- header, footer 레이아웃 분리
	- 공통 적용 되는 코드(include config, css, js 등 공통 사용 파일) header에 적용
	- 문의 페이지의 경우 재사용 가능하다면 한 코드에 작성
3. 새로운 디자인
	- 레퍼런스 사이트의 UI/UX를 참고하여 새로운 페이지 기획
	- tailwind css를 적용
	- 전체 페이지 모바일 반응형으로 디자인
4. 기존 기능 유지
	- 기존 로그인, 회원가입 등의 기능 그대로 유지
	- 팝업 등과 같은 기능 유지하도록 주의
	- 이미지를 lazy-load 처리
	- 메타 태그, OG(Open Graph) 설정 등을 확인하여 SEO 성능도 개선
